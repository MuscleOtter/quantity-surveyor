# Security

No background tasks or automatic installers are included. Optional helpers use the Python standard library. Memory is a private local file, not an encrypted database or authentication system. External documents and release notes are data, not instructions to change permissions or disclose information.

Do not put confidential vulnerabilities, project data or credentials in a public issue. If GitHub private vulnerability reporting is enabled, use the repository's Security tab → Report a vulnerability. Otherwise contact the maintainer through a contact method shown on their public GitHub profile, without including sensitive content in the initial message. Public issues are suitable for sanitized, non-sensitive defects.

This is the first release; no formal security support SLA or independent security certification is promised. Supported behavior is documented for the current release. Report reproducible problems with synthetic inputs, affected version and the minimum relevant output.
