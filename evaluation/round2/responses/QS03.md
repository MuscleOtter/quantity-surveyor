# Dimension-led takeoff — QS03

**Net installed quantities: stone floor 90.00 m²; gypsum wall finish 117.68 m²; base trim 38.20 m; slab 14.40 m³.** Stone procurement quantity before pack rounding is 100.80 m².

Basis: written dimensions and supplied project deduction rules in QS03 data; no drawing revision or visual plan file was supplied. The resized printed scale is unreliable and was not used. This is a project-convention takeoff, with no claimed compliance with a formal measurement standard.

| Item / source locator | Dimensions and deductions | Net installed quantity |
|---|---|---:|
| F01 Stone floor / room + floor_exclusions | 12.0 × 8.0 = 96.00 m² gross; deduct core 2.0 × 3.0 = 6.00 m² | 90.00 m² |
| W01 Gypsum wall finish / room + wall_openings + wall_rule | Perimeter 2 × (12.0 + 8.0) = 40.00 m; × height 3.2 = 128.00 m²; deduct door 1.8 × 2.4 = 4.32 m² and glazing 3.0 × 2.0 = 6.00 m² | 117.68 m² |
| B01 Base trim / base_trim_rule | 40.00 m perimeter − 1.80 m entry door; no glazing deduction because it starts above floor | 38.20 m |
| S01 Slab / slab.covers + slab.thickness_mm | 150 mm ÷ 1,000 = 0.150 m; full 12.0 × 8.0 × 0.150, including core | 14.40 m³ |

Stone procurement: 90.00 m² net × 12% = 10.80 m² waste; net + waste = 100.80 m². Waste is applied to net stone only and does not increase installed quantities or labour quantities. No waste factor was supplied for other items. Pack rounding awaits supplier format.

All listed wall openings are deducted; returns and core walls are ignored as instructed. No core deduction is made from the slab. Visual drawing checks and revision reconciliation remain outstanding because only explicit tabular dimensions were available. Calculations retain decimal precision; quantities display to two decimals.
