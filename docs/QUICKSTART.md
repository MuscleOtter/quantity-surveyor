# Your first project

Start with the decision you need, then attach the smallest useful set of inputs. The AI should start supported work and ask focused questions for material gaps.

## Take-off

> Use Universal Quantity Surveyor. Measure the facade in drawings E01 revision B and detail D03 revision C. Use the supplied deduction convention. Show gross area, each opening, net installed area, separately measured returns and purchased quantities with 7% material waste. Cite each drawing location. Use only the quoted rates I attach.

Provide readable drawings, dimensions/scale, revisions, the measurement convention and rate inclusions. If no prices exist, ask for a quantity schedule first.

## Whole building estimate

> Build a preliminary cost plan for this freestanding building from the attached scope and package rates. Include enabling works, structure, envelope, interiors, services, utilities/site works and owner costs. Distinguish measured costs, included scope, excluded scope and unpriced gaps. Show the base for every addition and reconcile to the total.

Provide location/currency, price date, area definition, programme, tax basis and known rate boundaries. The [project basis prompt](../skills/universal-quantity-surveyor/templates/project-basis.md) is optional.

## Forecast and changes

> Reconcile this approved budget, commitments, paid amounts and pending changes to forecast final cost. Determine which amendments replace a PO total and which are incremental. Show each change's inclusion point and separate financial state from code-mapping certainty.

Provide the definitions used by your project, revision dates and unique IDs. Matching labels do not establish authoritative code mappings.

## Tender or value engineering

> Compare these three facade bids. Preserve their submitted totals, normalize only evidence-backed scope differences and keep scenario allowances/unpriced qualifications visible. Rank only compliant options; identify the next clarification that matters most.

Provide exclusions, interfaces, performance/design constraints, access/logistics, approvals and programme requirements.

## Lifecycle options

> Compare these two compliant systems for 20 years using the supplied real discount rate. Include maintenance, replacement event dates, residual value and consistent tax/inflation treatment. Show discounted costs and sensitivities, then explain the decision.

Provide event timing, service-life evidence and discount/price bases. Unsupported service lives should remain assumptions.

## Good outputs

Ask for quantities with traceable dimensions, explicit units and revision locations; rates with inclusions; percentages with stated bases; a detail-to-total reconciliation; and a short query list ranked by decision impact. Unknown scope should remain visible rather than silently become zero. Keep private project files out of public issues and examples.

## Optional memory

Memory starts off. Enable only when you choose a private root, user and project scope. Read [memory-and-review.md](../skills/universal-quantity-surveyor/references/memory-and-review.md) before using the helper. Do not store project data inside the installed skill or this public repository. A scoped file is not encryption or access control.
